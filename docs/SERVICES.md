No live travel supplier, paid API, payment processor or in-app AI model is integrated.

Raised-globe refinement — 30 October 2026: no dependency, asset download or new external service. Existing local Natural Earth geometry now drives extrusion; existing country metadata supplies labels. Runtime map provider usage remains governed by the existing register; no new supplier/AI/payment calls were introduced.

Country relief workspace — 30 October 2026: explicitly approved downloads imported one Natural Earth 10m GeoJSON (13,287,234 bytes) and two Tilezen/Joerd documentation files (12,300 + 5,392 bytes). SHA-256 hashes and retrieval timestamps are retained in `client/public/relief/manifest.json`. The terrain import delivered 101 distinct zoom-5 Terrarium PNG tiles, totaling 7,999,475 cached bytes, from the public `elevation-tiles-prod` S3 dataset. No AWS account, token or paid service was used. The importer allowed at most 600 distinct tiles and up to three attempts per tile; the initial tool did not retain a separate failed-attempt counter, so 101 is the delivered unique-tile count, not a claim about all network attempts. Rebuilding models uses the local cache. Browsers fetch local GLBs and metadata and make no terrain-provider requests.

Terrain source attribution is served locally at `/relief/TERRAIN-ATTRIBUTION.md`, retaining the provider-specific notices from Tilezen/Joerd. Natural Earth is public-domain boundary data. The model manifest records projection, regional insets, eight-times height exaggeration, source records and generated file hashes/sizes. Zoom-5 elevation is coarse reference relief, not survey data. Negative samples are clamped to sea level.

Approved npm access added build-only `polygon-clipping`, `earcut` and `pngjs` as direct pinned development dependencies. `d3-geo` was initially promoted while evaluating projections, then removed as an unused direct dependency; the final regional projection uses shared explicit arithmetic. Package registry/retry request counts were not instrumented. npm reported zero known vulnerabilities for the installed graph at this checkpoint. Existing Three.js, React Globe and MapLibre remain the runtime engines.

New application interfaces: read-only `POST /api/estimates` and `POST /api/estimates/trip`; owned trip listings include shared pricing summaries. These use no external pricing API and log only the existing request count/status/duration fields. Estimates never create quotes or reserve inventory and have a separate 120-request/minute IP limiter. The final browser fixture evidence records its own scope; existing structured application logs remain the source for broader application counts.
