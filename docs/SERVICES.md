## Recording usage

This session: npm dependencies installed with approval; the security advisory service was queried and a patched Vitest installed (final audit: zero known vulnerabilities). MongoDB 7.0.14 was downloaded for approved local testing. The official k6 2.3.0 Windows binary was downloaded into .cache and checksum-verified with approval. k6 issued 1960 baseline browse, 6814 cached browse, and 20 contention requests. These are the k6 request totals only, excluding integration/browser tests and downloads. Exact registry/download HTTP call counts remain unknown. No Atlas, Render, or GitHub account has been connected.

At each session, update which services were actually called, permissions granted, and any known usage. Load tests write exact request counts and timings to `artifacts/loadtests`; the measured report must name the environment. Do not publish authentication cookies or the local `.env`. Platform dashboards become the source for hosted quotas and billing after an approved deployment.

Never log emails, passwords, cookie headers, JWTs, or full booking request bodies. Request IDs allow error correlation without storing personal input. No claim of exact external download counts is made because package managers perform their own retries and transitive requests.
